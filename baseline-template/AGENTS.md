# AGENTS.md — 项目约定

任何 agent 在本仓库工作前必读。

## 技术栈
- 纯静态单页应用:index.html + app.js + style.css,无构建步骤、无依赖、无框架。
- 状态保存在内存中即可,不引入 localStorage 除非任务明确要求。

## 改动规则
- 保持改动最小,只动与任务相关的文件。
- UI 文案使用简体中文;代码注释仅在解释非显而易见的约束时添加。
- 不新增任何 npm 依赖,不引入打包器。
- 完成后提交,信息格式:`task: <一句话中文摘要>`。

## 验证方式
- 用浏览器直接打开 index.html 手动验证功能。
- 涉及 JS 改动时,确保没有 console 报错。
